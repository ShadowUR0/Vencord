تحميل Windows GUI تحميل Windows CLI SHA256SUMS.txt

لا تشغل نسخة GUI كمسؤول Administrator

قد يعرض Windows تحذير SmartScreen لان الملفات غير موقعة رقميا حاليا

مثل Vencord الرسمي، الطريقة الاسهل على Linux هي تشغيل الانستولر من الطرفية. السكربت يكتشف تلقائيا x86_64 او arm64 ويحمل نسختنا فقط

sh -c "$(curl -fsSL https://shadowur0.github.io/Vencord/install.sh)"
Linux x86_64 Linux arm64 SHA256SUMS.txt

Discord المثبت عبر Snap غير مدعوم من الانستولر. استخدم Flatpak او حزمة Discord الرسمية بدلا منه
